## Descripción

Este proyecto consiste en la maquetación de una página web inspirada en el diseño proporcionado por el docente. El objetivo fue replicar la estructura visual utilizando HTML semántico y CSS, respetando lo más posible la distribución de los elementos, colores, imágenes y secciones presentes en la referencia.

## Aprendizajes

Durante la realización de este trabajo se reforzaron conocimientos relacionados con:

- Uso de HTML semántico.
- Distribución de elementos con CSS Grid.
- Uso de Flexbox para navegación y organización de contenido.

- Uso de Git y GitHub para el control de versiones.

---

## Dificultades Encontradas

Algunas de las dificultades presentadas fueron:

- Ajustar el tamaño de las imágenes para que mantuvieran una apariencia uniforme.
- Organizar correctamente las secciones para que se parecieran al diseño de referencia.
- Adaptar algunos elementos para dispositivos móviles.

---

## Soluciones Aplicadas

Para solucionar los inconvenientes se utilizaron:

- CSS Grid para las galerías y tarjetas.
- Flexbox para el encabezado y otras secciones.
- Media Queries para mejorar la visualización en diferentes pantallas.
- Ajustes de tamaño mediante la propiedad `object-fit: cover`.
